# CORVINA BAY 3D

An ambitious reimagining of the classic open-world crime browser game, rebuilt from the ground up using Three.js for immersive 3D graphics directly in the browser. The project delivers a seamless blend of exploration, action, and narrative in a vibrant urban environment.

## Features

- Real-time 3D rendering with Three.js
- Interactive open-world environment
- Dynamic character movement and vehicle mechanics
- Atmospheric lighting and day/night cycles
- Rich urban landscape with buildings, streets, and landmarks

## Run

```bash
npx -y serve .
```

Then open `/game/index.html` in your browser.
